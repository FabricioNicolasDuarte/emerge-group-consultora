1. Introducción

El Campus Virtual de Emerge Group es la plataforma donde se gestionan programas (cursos), inscripciones, contenidos, asistencia, calificaciones, comunicaciones, certificados y reportes.

Este manual explica:

  • Qué ve y puede hacer cada rol.
  • Cómo navegar cada sección del menú.
  • Cómo cargar datos (cursos, alumnos, Excel de inscripción, materiales, notas).
  • Qué efecto tiene cada acción (ej.: convertir una solicitud crea usuario + inscripción).
Cómo usar este documento. En el navegador, usá el botón Imprimir / Guardar PDF (o Ctrl+P). Activá “Encabezados y pies de página” si el navegador lo ofrece; el CSS del manual ya define título, confidencialidad y número de página.

1.1 Roles y paneles

Hay seis roles. En la práctica se agrupan en tres paneles:

RolPanel principalPara qué sirve

Después del login, el sistema redirige al panel del rol de mayor jerarquía. Si un usuario tiene más de un rol, puede cambiar de panel con el selector de roles.

2. Sitio público y catálogo

Ruta: /campus

La landing del Campus presenta la propuesta formativa, el catálogo de programas, el equipo docente, testimonios y anuncios públicos. No requiere iniciar sesión para recorrerla ni para abrir la ficha de un curso.

Qué hace cada bloque

  • Hero / CTA: invita a conocer programas o ingresar al campus.
  • Catálogo: lista cursos publicados; al hacer clic se abre la ficha.
  • Anuncios públicos: comunicados visibles sin login.

Ficha de curso (público)

Ruta: /campus/cursos/[slug]

  • Inscripción gratuita (precio 0): con sesión iniciada, el alumno se inscribe al instante.
  • Inscripción paga: si Mercado Pago está configurado, se inicia el checkout; el resultado vuelve a /campus/pagos/resultado.
  • Sin pagos online: puede mostrarse un contacto (mailto / WhatsApp) según configuración.

3. Acceso: login, registro y recuperación

3.1 Ingresar

Ruta: /campus/login

  1. Abrí /campus/login.
  2. Completá correo y contraseña.
  3. Opcional: marcá Recordarme para guardar el correo en el navegador.
  4. Pulsá Ingresar al Campus. El sistema te lleva a tu panel según el rol.

¿Olvidaste tu contraseña? Escribí el correo y usá el enlace de recuperación. Recibirás un mail con link a /campus/restablecer-contrasena.

3.2 Registrarse

Ruta: /campus/registro

El auto-registro crea una cuenta con rol alumno. Para altas masivas de una cohorte (Diplomatura), preferí el flujo de Solicitudes → Importar Excel.

6.2 Cursos

Ruta: /campus/admin/cursos

Acciones por fila (típicas): Contenido · Asistencia · Notas · Cohorte · Precio · Docente · Publicar/Ocultar.

Crear un curso

  1. Pulsá + Nuevo curso.
  2. Completá título, categoría, descripción y estado (borrador / publicado).
  3. Definí precio (0 = gratuito) y, si aplica, cohorte (fechas, cupo, ventana de inscripción).
  4. Guardá. Luego asigná docentes y cargá contenido.
Publicar hace visible el curso en el catálogo público. En borrador solo lo ven quienes tienen acceso al panel.

6.3 Alumnos

Ruta: /campus/admin/alumnos

  • Importar Excel: atajo a Solicitudes (alta masiva).
  • + Nuevo alumno: alta manual con ficha.
  • + Nueva inscripción / Inscribir: vincula alumno existente a un curso.

Alta manual con ficha

  1. Completá nombre, correo y contraseña temporal (mín. 8 caracteres).
  2. Opcional: cargá la ficha completa (útil para seguimiento comercial/académico).
  3. Crear alumno → la cuenta queda lista para login.
  4. Inscribilo a un curso desde Inscripciones o el botón Inscribir de la fila.
Comunicá la contraseña temporal por un canal seguro (WhatsApp / mail). Pedile al alumno que la cambie si tu política lo requiere.

6.4 Inscripciones

Una inscripción vincula un perfil alumno a un curso con estado (activo, etc.) y habilita el acceso al contenido, la toma de asistencia y las notas.

6.5 Solicitudes e importación Excel

Ruta: /campus/admin/solicitudes

Esta pantalla resuelve el ingreso masivo desde Excel (p. ej. Diplomatura). Cada fila es una ficha, no todavía una cuenta.

EstadoOrigen típicoQué hacer
Listo (verde)Fila verde en ExcelIncluir en “Crear todos los listos”
En duda (naranja)Fila naranjaConfirmar datos → Marcar listo
ConvertidoYa se creó usuarioNo volver a convertir
RechazadoManualQueda fuera del alta

Cómo importar

  1. Pulsá Importar Excel.
  2. Elegí el curso destino (debe existir y preferentemente estar publicado).
  3. Seleccioná el archivo .xlsx. El sistema lee colores y columnas: nombre, email, WhatsApp, audiencia, desafío, rol laboral, ocupación, ciudad.
  4. Revisá el resumen: cantidad de listos vs en duda.
  5. Opcional: filtrá, buscá, marcá naranjas como listos o rechazá.
  6. Pulsá Crear todos los listos (o seleccioná filas → Crear seleccionados).
  7. Descargá el CSV de contraseñas temporales y envialas a cada persona.
Reimportar el mismo email+curso actualiza la ficha sin pisar convertidos. Si el email ya tenía cuenta, se reutiliza y solo se crea/asegura la inscripción.

6.6 Gestión de un curso: contenido, asistencia y notas

Contenido

  1. Creá módulos (unidades temáticas).
  2. Dentro de cada módulo, agregá lecciones (título, texto, URL de video).
  3. Subí materiales (PDF, etc.) y publicá cuando estén listos.
  4. El alumno ve solo lo publicado, si está inscrito.

Asistencia

  1. Creá una sesión (fecha, horario, link de reunión si aplica).
  2. Marcá cada alumno: presente / ausente / tarde / justificado.
  3. Podés usar “marcar todos presentes” y luego ajustar excepciones.

Calificaciones

  1. Creá una evaluación (nombre, tipo, puntaje máximo).
  2. Completá la grilla alumno × evaluación.
  3. Guardá; el alumno lo verá en Mis notas.

8. Flujos operativos recomendados

8.1 Armar un programa nuevo de punta a punta

  1. Admin → Cursos → Nuevo curso (borrador).
  2. Asignar docente/tutor.
  3. Cargar Contenido (módulos y lecciones).
  4. Definir precio y cohorte.
  5. Publicar el curso.
  6. Ingresar alumnos (manual o Excel) e inscribir.
  7. Crear sesiones de asistencia y evaluaciones.
  8. Al cierre: emitir certificados y revisar reportes.

8.2 Alta masiva Diplomatura (Excel)

  1. Tener el curso Diplomatura creado.
  2. Admin → Solicitudes → Importar Excel (verde/naranja).
  3. Revisar en duda → Marcar listo cuando corresponda.
  4. Crear todos los listos → Descargar CSV de claves.
  5. Enviar credenciales + link /campus/login.

8.3 Clase en vivo (asistencia)

  1. Docente o admin abre Asistencia del curso.
  2. Crea la sesión del día (con link Meet/Zoom si aplica).
  3. Marca asistencia al cierre.
  4. El alumno lo ve reflejado en su panel.

9. Preguntas frecuentes

¿Por qué no veo Auditoría?

Solo el rol superadmin tiene esa entrada en el menú.

¿Dónde se gestionan los pagos?

No hay un menú “Pagos” en admin. El cobro ocurre en la ficha del curso (Mercado Pago) y el retorno en /campus/pagos/resultado. Si no hay token de MP configurado, los pagos online quedan deshabilitados.

Importé el Excel pero no se crearon usuarios

La importación solo carga solicitudes. Tenés que pulsar Crear todos los listos (o seleccionados) y luego bajar el CSV.

El alumno no ve el contenido

Verificá: 1) inscripción activa, 2) curso/lecciones publicados, 3) sesión iniciada con la cuenta correcta.

¿Puedo usar usuarios de prueba en producción?

No. Los usuarios @test.emerge.local son solo para desarrollo/capacitación local.
